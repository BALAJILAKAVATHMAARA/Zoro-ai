# ZORO AI - Phase 1
1. Android Studio (Koala or newer) > File > Open > select the ZoroAI folder. Let Gradle sync (needs internet, JDK 17 is bundled).
2. Plug in your phone (USB debugging on) > press Run.
3. Tap MIC, allow microphone, say: "open YouTube", "turn on the flashlight", "set an alarm for 7 30 am",
   "volume up", "battery", "search kotlin tutorials", "what time is it".
